由于我现在在做的几个不同的垂直化个人代理都需要用到图像和视频生成的功能，所以我不得不在中台层面去解决这个问题。然后我发现，相对于 ComfyUI 的云服务的调度能实现更大的自由度，使用 fal 等这种线上的 API 来做，完全就只能根据商业化的逻辑和成本来控制。这其中就是有一个明显的一个差距，你没有办法完全自由自在地生成东西。不是说 R18 加的东西，是所有东西你都没有办法完全自由自在地生成。也就是说，没有一个服务可以做到这种基线，现有的所有图像和视频生成服务似乎都对这个基线的理解各有差异。Claude Code 的办法是通过一些脚本和预剪辑，在导演层面来实现。我不管切换什么样的模型，是 ComfyUI 当中的工作流的模型，还是 fal 等线上的 API 的模型，都可以达到高度的一致化。但做这件事情的前提是，这个 benchmark 需要你有一台本地的机器，来不断地使用导演模型进行反复审阅，才有可能在不同的导演模型在跑这个 benchmark 的前提下，评分达到几乎一致。
所以我发现，其实相比于使用 API 来进行图像和视频生成，如果你有大规模的需求和高度一致化的长篇视频的需求的话，那么租用云 GPU 是唯一不二的选择。
